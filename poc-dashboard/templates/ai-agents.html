AI Agents — DefenseClaw

Enterprise security governance for agentic AI — powered by Cisco DefenseClaw and OpenClaw.

WHAT IS DEFENSECLAW?

OpenClaw is the LLM agent (the brain that reasons and calls tools); DefenseClaw is Cisco’s open-source security gateway (the immune system) that scans every skill, inspects every tool call, and blocks secrets leakage, prompt injection, and command-and-control.

Use the guided setup below to pick an LLM provider, deploy the agent into your k3s cluster, stream its traces to Splunk Agent Observability, and give it a Duo Agentic Identity.

COMPONENTS

OpenClaw Agent

LLM-powered agent that reasons, plans, and calls tools. Hosts the DefenseClaw plugin which intercepts every tool call via a before_tool_call hook.

DefenseClaw Gateway

Go-based policy engine. Runs CodeGuard static analysis, skill/MCP scanning, tool inspection, and a guardrail LLM proxy. Logs every allow/block/warn decision (Splunk SIEM forwarding optional).

CLI Dashboard

Python TUI for operators. Trigger scans, review audit logs, manage policies, and watch agent activity in real time — all from the terminal.

Agent Observability

The agent streams its GenAI traces, token usage and cost to Splunk Observability Cloud (Agent Observability) — configured in the setup below. No OTel Collector required.

ⓘ Where do I get the realm & token?
Your realm (e.g. us1, eu0) is under Splunk Observability Cloud → Settings → (your name) → Organizations. Create an access token under Settings → Access Tokens → New Token (API scope). For Agent Observability keys use the profile menu → API keys. Docs.

ⓘ Where do I get these?
Duo Admin Panel → Applications → your MCP / OAuth agent application → Clients tab → Confidential Client Registration. The Duo page can create the PoC Users group, permit it on this app, and provision the agent application.
